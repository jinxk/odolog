# Code of conduct

Be kind. Assume good faith, keep it civil, and remember there is a person on the other end of every issue and review.

That covers almost everything. To be specific about the rest: harassment, personal attacks, insults about who someone is, and posting someone's private information are not acceptable here, in an issue, a pull request, a review, or anywhere else this project happens.

Disagreement is fine and useful. A rejected pull request is not an insult, and neither is a request for changes.

## If something goes wrong

Email aniket.kotkar.w@gmail.com. I read it, and I will keep what you tell me to myself.

I maintain this project, so enforcement is mine: a warning, then removal of the comment or the pull request, then a block, depending on what happened.
