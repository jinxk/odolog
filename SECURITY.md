# Security

OdoLog stores everything on the device and talks to no server, so the attack surface is small. It is not zero: a bug in the backup import, in the file handling, or in the notification code could still matter.

## Reporting

Email aniket.kotkar.w@gmail.com with what you found and how to reproduce it. Please do not open a public issue for a security bug.

Expect a reply within a week. There is no bounty; this is a free app I maintain in my own time.

## Supported versions

The latest release is the one that gets fixes. Older versions do not get backports.
